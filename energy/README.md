# 宝可梦 · 能量岛冒险

离线优先的六关探索、弹幕战斗与知识复习游戏。针对 iPad 横屏，同时支持电脑。

## 运行

无需构建与第三方运行依赖。使用 `python3 -m http.server 8765`，访问 `http://localhost:8765/`。不要直接以 file:// 打开；题库载入与离线缓存需要 HTTP。

## 操作

- 摇杆 / WASD / 方向键：移动；电脑也可点击地面。
- 普攻自动发射；空格 / 右侧按钮：招式。
- E / 交互：激活附近装置与补给。
- 收集每3块同属性方块、激活装置、领取补给及首领挑战节点暂停答题；答题不限时，独立答对补充2点能量，解析手动继续，错题先订正。

## 内容

993道成语、49首古诗98题、60道字词句子、136道英语词义及104道情景对话（后者共享26个交际知识点），数学按范围程序化生成。实际数量以数据检查为准。题目补充与古诗方向、节选说明在数据中整理。题库清单密码：0023（仅入口限制）。

## 数据与离线

本地存档使用 localStorage，保存关键结算及每5秒场景快照。设置页导入/导出JSON备份。首次联网成功后 Service Worker 缓存游戏和所有本地素材；离线就绪后可断网玩。更新采用版本化缓存。清除网站数据会删除存档与离线缓存。

## 验证

使用 Node 运行 `node --test tests/*.test.mjs`。浏览器验收覆盖首次选伙伴、范围筛选、移动收集、答题订正、战斗、续关、奖励与离线。

## 素材

宝可梦官方立绘与动画精灵来自 PokeAPI sprites 项目镜像，见 `assets/ATTRIBUTION.md`。宝可梦角色、名称与官方美术归相应权利人所有；本项目为非官方学习游戏。自定义强化形态使用已有官方形态立绘配合原创光效，并在图鉴标识，不冒充官方形态立绘。
